Detailed Description

An index of where the gref paths lie in the graph.

For each node, it holds the gref path that visits it and the path coordinate of its first base. For each gref path, it holds the steps. With these, it places walk intervals on the gref.

Index the GBWT paths whose name starts with the given prefix.

The paths are numbered in order along the gref. They are in byte order of their names without any _<N>_alt suffix. Among the paths that share such a name, the path with no suffix comes first and the alt contigs follow in order of N. Paths with the same name are in order of where they start on the full path.

GrefPlacement vg::GrefIndex::place ( const WalkInterval &  interval,

Return where the interval lies on the gref.

Bases between two runs on one path become edits. Bases between runs on different paths become an insertion at the end of the earlier segment. Where the interval leaves an alt contig before its end, the bases up to the step from step_past_contig_end() would be an insertion. They become edits against the rest of the contig instead, and the start of an alt contig works the same way. An interval that goes straight from the contig to that step has no bases there, and keeps its placement.

Parameters
beforeThe node before the interval on the walk it comes from, if any, such as the reference node before a variant allele. The walk can come past the start of an alt contig from it.
afterThe node after the interval, likewise. The walk can rejoin the graph past the end of an alt contig there.

Return the step from which a walk that joins an alt contig after its start comes past that start, or nothing.

This mirrors step_past_contig_end(). The walk visits the contig at first_step. An earlier step that the contig's first node follows in the graph, as the walk reads the contig, means that the steps between take the place of the start of the contig.

◆ step_past_contig_end()

std::optional< size_t > vg::GrefIndex::step_past_contig_end ( const std::vector< handlegraph::handle_t > &  walk,
size_t  last_step,
uint32_t  contig,
bool  is_reverse 
) const

Return the step at which a walk that left an alt contig before its end rejoins the graph past that end, or nothing.

The walk visits the contig at last_step, reading it in reverse if is_reverse, and the contig goes on past that node. A later step that follows the contig's last node in the graph, as the walk reads the contig, means that the steps between take the place of the rest of the contig. The search stops at the next visit to the contig. It also stops after a visit to the reference, which lies outside every contig. Only the step that ends the search can be on the reference, next to where the contig branches off.
