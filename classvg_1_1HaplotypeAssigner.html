Detailed Description

Answers two questions about an alignment's path, from a GBZ: which haplotypes follow it, and where those haplotypes leave the snarl around it. Thread-safe.

◆ segments()

vector< HaplotypeSegment > vg::HaplotypeAssigner::segments ( const Alignment &  aln) const

Split the alignment's path into segments, in path order, each one as long as some haplotype follows it. A path that one haplotype follows end to end is one segment. A node that no haplotype visits is in no segment.

◆ snarl_boundaries()

SnarlBoundaries vg::HaplotypeAssigner::snarl_boundaries ( const Alignment &  aln) const

Find the boundary nodes of the smallest snarl that contains the alignment's whole path.

Walk out from each end of the path while the haplotypes that follow the whole path all take the same node, through child snarls, to the first node outside that snarl. The walk to the right uses only the haplotypes that were left at the end of the walk to the left.

A side is unset if no haplotype follows the whole path, no snarl contains it, the haplotypes part before they leave the snarl, or the walk takes more than max_extension_nodes steps.
