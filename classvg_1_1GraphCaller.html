◆ call_top_level_snarls()

void vg::GraphCaller::call_top_level_snarls ( const HandleGraph &  graph,
RecurseType  recurse_type = RecurseOnFail 
)
virtual

Run call_snarl() on every top-level snarl in the manager, in parallel, and then on children as recurse_type says.

RecurseAlways calls the children of every snarl, RecurseOnFail the children of each snarl whose call returned false, and RecurseNever no children. Calling continues down the snarl tree the same way.

Each snarl is its own parallel job, unless set_snarl_batching(w) was called. Then each job calls, in node-ID order, the top-level snarls whose lower boundary node ID is in one window [k*w, (k+1)*w). Children are always one job each, started in node-ID order.

◆ set_snarl_batching()

void vg::GraphCaller::set_snarl_batching ( size_t  window_size)

Make call_top_level_snarls call top-level snarls in batches, by windows of window_size node IDs.

This suits a SnarlCaller that loads its reads one window of node IDs at a time. A size of 0 gives one job per snarl.
