Detailed Description

The result of surjecting an alignment onto a haplotype path: where it lands, or why it could not be placed. Fields other than status are set only when status is OK.

Enumerator
OK 

The alignment was surjected onto the target path.

EMPTY_INPUT 

The alignment has no graph path.

UNKNOWN_PATH 

The graph has no path with the target's name.

PATH_NOT_INDEXED 

The graph has the target path, but its positions are not indexed.

INCOMPATIBLE 

The target path does not carry the alignment's path.

SURJECTION_FAILED 

The surjector found no alignment on the target path.
