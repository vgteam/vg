Detailed Description

A run of steps of a path, from step_begin to step_end inclusive, with the path offsets of both steps. surject_with_anchors() gets its positions on the target path from these.

Each step is a GBWT node and an offset in that node's GBWT record, which is how GBWTGraph encodes a step handle.
