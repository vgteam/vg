Detailed Description

Holds Giraffe's indexes and a mapper, and maps and surjects reads with them.

The engine maps batches of reads. It can find the haplotypes that carry each alignment's path, and can surject the alignment onto one haplotype path. A path indexed at load time can be a surjection target for map_reads(). Any other path can be a target for surject_with_anchors(), given anchors that place some of its steps on the path.

◆ map_reads()

vector< MappedRead > vg::GiraffeEngine::map_reads ( const std::vector< GiraffeServerRequest > &  reads)

Map a batch of reads.

Return one MappedRead per read, in input order. Each alignment has its haplotypes and, if the read names a surjection target, its surjection.

Each read is mapped in an OpenMP task. Call this from inside a parallel region to map on all its threads. Outside of one, the reads are mapped one at a time.

If mapping a read throws, the read has no name, or its qualities and sequence differ in length, the read gets the message as its error. The other reads are still mapped.

Exceptions
std::runtime_errorif the engine is not loaded.

HaplotypeSurjectionResult vg::GiraffeEngine::surject_with_anchors ( const Alignment &  aln,

Surject a graph alignment onto a haplotype path, using anchors on the path for positions.

The anchors stand in for a position index of the whole path, which the engine has only for the paths indexed at load time.

target_haplotype is a path name, such as GRCh38#0#chrM, or a sample and haplotype, such as HG002#2. For a name the graph does not have, the target is the path of the first anchor's step. The result's path_name is the name of the path that was used.

Precondition
All anchors lie on one path.
Parameters
target_path_lengthLength of the target path in bases, or 0 to have it computed here by walking the path.
Exceptions
std::runtime_errorif the engine is not loaded. An exception from the surjector is not caught.
