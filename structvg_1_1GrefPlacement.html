◆ along_one_path

bool vg::GrefPlacement::along_one_path = false

True if the whole interval lies along one gref path, so that the gref path visits it.

◆ coord

uint64_t vg::GrefPlacement::coord = 0

The lowest coordinate of the first segment. Placements sort along the gref by path, then coord, and a placement with no path sorts last.

The path of the first segment, or GrefIndex::NO_PATH if no base is on the gref.

◆ regions

std::string vg::GrefPlacement::regions

The segments of the text without their CIGARs, each as PATH:START-END:STRAND, or * if no base is on the gref. PATH has no subrange, and START and END are on the full path.

◆ reverse_bases

size_t vg::GrefPlacement::reverse_bases = 0

Number of bases on gref paths that the paths read in reverse.

◆ text

std::string vg::GrefPlacement::text

Comma-separated PATH:START-END:STRAND:CIGAR segments (1-based, inclusive, CIGAR in path order), or *:<length>I if no base is on the gref.
