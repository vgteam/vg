Detailed Description

Finds traversals with the most flow. Node and edge weights are specified using the callbacks and can be used, ex, to yield read supports.
If one traversal is requested, then the path with the highest flow (whose node or edge with the minimum weight is maximum) is returned. If K traversals are specified, then the K highest flow traversals are returned. This is designed to be a replacement for RepresentativeTraversalFinder. It should do a better job of enumerating off-reference traversals, and will of course guarantee to return all the optimal traversals (in the context of max flow). Unlike RepresentativeTraversalFinder, it does not currently support nested snarls, so all traversals returned are explicit.
It is possible that it will blow up on massive snarls, espeically for large Ks.

edge_weight_callbackA function giving the flow through an edge.
max_traversal_lengthA length in bases. When a search finds a traversal longer than this, not counting the site's bounds, it stops and returns the traversals found so far, including that one.
greedy_avg_thresholdA length in bases. A site with more than this many bases inside its bounds is searched with the greedy average-flow heuristic.

Find the K widest traversals through the site between two bound handles, with their flows.

Parameters
snarl_startThe start bound of the site, oriented into the site.
snarl_endThe end bound of the site, oriented out of the site.
greedy_avgTrue to search heuristically by the running average flow, which may miss the widest traversals, rather than by the smallest flow along each traversal.
overlayA graph to search instead of the finder's graph, or null. If given, the bound handles must be in the overlay, and the traversals are returned as handles in it.
Returns
The traversals, and a vector whose i-th entry is the flow through the i-th traversal. Without greedy_avg, the traversals come widest first. With greedy_avg, each flow is an average of the weights along the traversal, and a traversal can have more flow than the one before it.
