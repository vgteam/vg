Detailed Description

vg giraffe-server: load the Giraffe indexes once, then answer the requests streamed on stdin with frames on stdout.

The rule for requests and errors:

  • A request is one read line, or one SURJECT_WITH_ANCHORS block.
  • Every request gets exactly one frame: a result frame or an error frame.
  • An error in a request affects only that request. The server goes on.
  • A line that is neither a request nor PROCESS_BATCH gets an error frame with the name *. Empty lines are skipped.
  • A frame is written whole. A client never sees half of one.
  • The server stops at end of input, after answering everything it read. Before the first request it also stops on a failure (options, indexes).
