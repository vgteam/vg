std::vector<std::pair<std::string, std::string> > vg::subcommand::GiraffeParameters::options

options set on top of the presets. Each one of the options is a giraffe long option name without the dashes example for one vector element: {"max-multimaps", "20"}. A flag has no value. Also the options replace preset values if duplicated.
