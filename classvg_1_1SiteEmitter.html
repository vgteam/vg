Detailed Description

An emitter that accepts CalledSites and produces VCF records into a SortedVCFWriter.

It can be subclassed to customize its VCF record generation behavior.

Write the record of site.

Traversals that spell the same sequence become one allele. Where the genotype has an allele marker, the record has "*" or ".", and a genotype with "." and no ALT gets "*" as its ALT, so that the record is valid VCF. A record with no ALT is hidden unless genotype_snarls is set.

Parameters
allelesSpells the site's traversals.
write_fieldsWrites the genotyper's fields once the alleles are numbered.
Returns
false only if the writer refused a line the site wanted.

Number the reference allele and the alleles of the called genotype of site, whose REF is already in record. Traversals that spell the same sequence share one allele, and the reference allele is number 0.

Fill the empty allele_to_gt with the VCF allele number of each allele sequence, and the empty site_trav with the traversal each VCF allele is spelled from, or -1 for "*". Fill in record.genotype and record.trav_to_allele to match.

Decide how the genotype should be phased. Return the phase set it should be in, or -1 for none, and replace the GT string gt with the phased one if it should be phased. genotype is in VCF allele numbers, and trav_to_allele gives the VCF allele of each traversal in it. By default the genotype should stay unphased, in no phase set.
