Detailed Description

Gives a PathHandleGraph path positions on one target path, without a position index.

The positions come from anchors: steps whose positions the caller already knows. A position query walks the path from the nearest step with a known position and remembers every step it passes. Everything else goes to the base graph.

The graph is built for surjecting one read onto the target path. Only the steps of the target path inside the anchors' runs are reported as steps on their nodes, so a Surjector ignores the many other haplotype paths on each node.

Precondition
The anchors' runs cover every step of the target path that a surjected alignment visits.
Note
Position queries change the cache of known positions, so one object must not be queried from two threads at once.
