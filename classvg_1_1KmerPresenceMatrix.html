Detailed Description

A compressed binary matrix with haplotype sequences as rows and k-mers as columns. Set bits indicate k-mers that are present in the corresponding sequence.

The compression assumes that the matrix consists of clusters of similar sequences. We choose one sequence from each cluster as a parent and store it explicitly. For the other sequences (children), we only store the symmetric difference with their parent sequence. The internal representation reorders the sequences so that the parent of each cluster appears first, followed by its children.

◆ score_sequences()

void vg::KmerPresenceMatrix::score_sequences ( const std::vector< std::pair< kmer_classification, double >> &  kmers,
const std::function< void(size_t, double)> &  sequence_score 
) const

Scores every sequence in the subchain. The score of a sequence is the sum of (present : 1 : -1) * kmer.second over kmers. It is reported by calling sequence_score(sequence, score) in an arbitrary order.

NOTE: Because we reuse the score of a parent when scoring its children, the scores are often different from what we would get by scoring each sequence independently. This is due to numerical instability with floating point arithmetic.
